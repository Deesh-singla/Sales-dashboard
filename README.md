# Sales Dashboard

A Power BI dashboard created to analyze sales performance and identify key business trends and insights.

## 🛠️ Tools Used

- Power BI
- Power Query
- Data Modeling

## 📊 Dashboard Overview

The dashboard provides an overview of sales performance through interactive visuals and KPIs.

### Key Metrics

- Total Sales
- Total Profit
- Total Orders
- Sales Performance over Time
- Sales by Category
- Sales by Region

## 🔍 Key Analysis

The dashboard helps analyze:

- Overall sales and profitability
- Monthly sales trends
- Product/category performance
- Regional sales performance
- High-performing and low-performing segments

## 🎯 Objective

The objective of this project is to transform raw sales data into an interactive dashboard that can help understand business performance and support data-driven decision making.
